## Troubleshooting

| Issue | Solution |
|-------|----------|
| Page 404s after publish | Re-check URL slug in Gumroad dashboard; edit and re-save |
| Wrong price displayed | Edit product → confirm price field → save |
| Download fails | Re-upload file; verify file is not corrupted |
| Email missing download link | Check spam folder; confirm product is published (not draft) |
| Description formatting broken | Use Gumroad's Markdown preview before saving |
| Cover image too small | Use 1280x720px minimum; files in `scripts/launch/covers/` are pre-sized |
| Bundle ZIP won't upload | Ensure ZIP is under 500MB; use standard ZIP format (not 7z or rar) |
