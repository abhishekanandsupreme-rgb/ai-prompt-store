## Slide 3 — DEBUGGING PROMPT

**Headline:**
1. Context-First Debugging

**Body:**
> I'm working in [LANGUAGE/FRAMEWORK] version [VERSION].
> Code:
> ```[LANGUAGE]
> [PASTE CODE]
> ```
> Error:
> ```
> [PASTE FULL ERROR]
> ```
> Expected: [WHAT SHOULD HAPPEN]
> Actual: [WHAT'S HAPPENING]
> I've tried: [LIST FIXES ATTEMPTED]
>
> Please explain the root cause and provide a fixed version with comments.

**Pro tip:** Paste the FULL stack trace, not just "it broke."

**Visual:**
Bug icon with a magnifying glass.

## Slide 4 — REFACTORING PROMPT

**Headline:**
2. Safe Refactoring

**Body:**
> Refactor this [LANGUAGE] code to [GOAL: reduce complexity / improve performance / separate concerns].
> Constraints:
> - Do NOT change the public API
> - Do NOT introduce new dependencies
> - Maintain or improve test coverage
> - Add comments explaining non-obvious changes
>
> Original code:
> ```[LANGUAGE]
> [PASTE CODE]
> ```
>
> Show the refactored version and explain each change.

Before/after code comparison.
